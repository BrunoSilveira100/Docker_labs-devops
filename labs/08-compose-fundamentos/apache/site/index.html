Apache HTTP Server 2.4 em container

Bruno Silveira

Como esta página chega até você

  1. O arquivo site/index.html está no host (Windows).
  2. Um bind mount mapeia site/ para /usr/local/apache2/htdocs dentro do container.
  3. O httpd.conf customizado também é montado, em modo somente leitura.
  4. A porta 80 do container é publicada na porta 8080 do host.

Como provar que a configuração é a minha

curl.exe -i http://localhost:8080

A resposta traz os cabeçalhos X-Servido-Por e X-Autor, definidos no meu httpd.conf. A imagem oficial não tem esses cabeçalhos.

Teste de bind mount

Edite este arquivo com o container rodando e recarregue a página. A mudança aparece na hora, sem rebuild e sem reiniciar o container.
