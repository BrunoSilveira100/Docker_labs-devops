Nginx como servidor estático e proxy reverso

Bruno Silveira

Caminho de uma requisição /api/*

navegador→:8081 nginx→backend:4000

O Nginx encontra o container backend pelo nome, usando o DNS da rede bridge customizada. O backend não publica nenhuma porta no host: o único caminho até ele é o proxy.

Teste ao vivo

Clique em um botão para chamar a API através do proxy.

Pela linha de comando

curl.exe -i http://localhost:8081/api/status
